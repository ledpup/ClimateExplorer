- **Implementation order:** step 1 of 18; see [overview](2026-10-28-01-blazorise-removal-overview-plan.md#implementation-order)

## Current state

- Font Awesome **Free 6.6.0** comes from the `Blazorise.Icons.FontAwesome` 2.0.3 package
  (`_content/Blazorise.Icons.FontAwesome/v6/css/all.min.css`). `App.razor` loads it with the async
  preload pattern (`rel="preload" … onload="this.rel='stylesheet'"` plus a `<noscript>` fallback).
- `AddFontAwesomeIcons()` is registered in both `Program.cs` files. Nothing in the app uses
  Blazorise's `<Icon>` component; every icon is a plain `<i class="fas fa-…">`.
- Only the **solid** style is used (`fas` ~73 uses, `fa-solid` 3). No `far`/`fab`. About 36 distinct
  icons, including two computed in C#: `ClimateRecords.SortToggleIcon` (`fa-temperature-arrow-up/down`)
  and `SortIcon`.
- `all.min.css` also carries the regular, brands and v4-compatibility font-faces and shims, which we
  don't use. The fonts load lazily, so the cost is mostly CSS parse.
- **Open Iconic** is a second icon font, pulled in by `@import url('open-iconic/…')` at the top of
  `app.css`. The `@import` is a chained, render-blocking request. Used 8 times:

| File | Icon |
|---|---|
| `Components/Common/Collapsible.razor` | `oi-chevron-bottom`, `oi-chevron-right` |
| `Components/Chart/ChartSeriesView.razor` | `oi-chevron-top`, `oi-chevron-bottom` |
| `Components/Chart/DataSetBrowser/DataSetFolderList.razor` | `oi-plus` (via `ClimateButton Icon=`) |
| `Components/Common/Trends/TrendStatTable.razor` | `oi-chevron-right` |
| `Components/RecentObservations/RecentObservationsPanel.razor` | `oi-chevron-right` |
| `Components/RecentObservations/Tab/RecentObservationMainPanel.razor` | `oi-chevron-right` |
| `Components/SuggestedCharts.razor` | `oi-chevron-bottom` |

  Global CSS also targets `.oi` directly (`.trend-stats .trends-stat-chevron.oi` in `app.css`), and so
  do scoped files (`Collapsible.razor.css` and the recent-observations CSS).

## Options for Font Awesome

| Option | Call-site churn | Payload | Notes |
|---|---|---|---|
| **A. Vendor FA Free 6.x, solid only** (recommended) | None | `fontawesome.min.css` + `solid.min.css` + `fa-solid-900.woff2` | Same approach as vendored Chart.js. Same-origin, cacheable, fingerprinted via `@Assets`. |
| B. CDN (cdnjs/jsdelivr) | None | Same as A | Another third-party origin on the critical path. The repo is moving the other way (Chart.js vendored). |
| C. Inline SVG `Icon` component (~36 icons as path data in C#) | ~110 call sites, plus the `Icon` string parameters on `ClimateButton`/`DropdownButton` | No font, no icon CSS; a few KB of SVG in the WASM | Best performance, no flash of missing icon. A bigger change; worth it later, not as part of the Blazorise removal. |

**Recommendation: A now, C as an optional follow-up.** Stay on the latest 6.x release. Font Awesome 7
exists, but it renames and reshapes some icons, which would turn a dependency move into a visual change.

## Plan

### Step 1 — Vendor Font Awesome

1. Download Font Awesome Free 6.x (latest 6.x release) and copy into
   `ClimateExplorer.Web.Client/wwwroot/lib/fontawesome/`:
   - `css/fontawesome.min.css`, `css/solid.min.css`
   - `webfonts/fa-solid-900.woff2` (drop `.ttf`; woff2 is universally supported)
   - `LICENSE.txt` (Icons CC BY 4.0, Fonts SIL OFL 1.1, Code MIT; the CSS header comment must stay)
2. In `App.razor`, replace the two `_content/Blazorise.Icons.FontAwesome/v6/css/all.min.css` references
   (preload and noscript) with two links each, for `lib/fontawesome/css/fontawesome.min.css` and
   `lib/fontawesome/css/solid.min.css`, keeping the async-preload pattern. Optionally concatenate the
   two into one `fontawesome-solid.min.css` to save a request.
3. Add a `<link rel="preload" as="font" type="font/woff2" crossorigin>` for `fa-solid-900.woff2`. Icons
   appear in the nav and first-viewport buttons, so preloading the one font avoids a late swap.
4. Add a line to AGENTS.md next to the Chart.js note: Font Awesome is vendored in
   `wwwroot/lib/fontawesome` (version, solid only), and adding a `far`/`fab` icon means vendoring that style too.

`AddFontAwesomeIcons()` and the package reference stay until plan 17. They're harmless once nothing
references the package's static assets.

### Step 2 — Fold Open Iconic into Font Awesome

| Open Iconic | Font Awesome |
|---|---|
| `oi oi-chevron-bottom` | `fas fa-chevron-down` |
| `oi oi-chevron-top` | `fas fa-chevron-up` |
| `oi oi-chevron-right` | `fas fa-chevron-right` |
| `oi oi-plus` | `fas fa-plus` |

1. Swap the classes in the 7 Razor files above.
2. Update the CSS that selects `.oi` (`app.css` `.trends-stat-chevron.oi`, `Collapsible.razor.css`,
   recent-observation chevron rules) to select the element's own class instead (e.g.
   `.trends-stat-chevron`), so the CSS no longer cares which icon font is used.
3. Open Iconic glyphs are drawn at a different size and baseline from Font Awesome's (`.oi` has
   `top: 1px; line-height: 1`). Expect to adjust `font-size`/`vertical-align` on the chevrons
   (generally FA chevrons look heavier, so `font-size: 0.75em`–`0.85em` is a starting point). Rotation
   animations (`.expanded { transform: rotate(90deg) }`) carry over unchanged.
4. Remove `@import url('open-iconic/…')` from `app.css` and delete `wwwroot/css/open-iconic/`.

### Step 3 (optional, later) — SVG `Icon` component

Out of scope here. If pursued: `Components/Common/Icon.razor` renders
`<svg aria-hidden="true" class="climate-icon" viewBox="…"><path d="…"/></svg>` from a static
`IconPaths` dictionary keyed by FA name. `ClimateButton.Icon`/`DropdownButton.Icon` switch from CSS
class strings to icon names, and the vendored font is deleted. Its own plan when wanted.

  ClimateRecords sort toggle (computed class).
- Chevrons in Collapsible, ChartSeriesView, SuggestedCharts and the trend stat table rotate and align

## Summary

Font Awesome keeps the same classes, but its files come from a vendored, solid-only copy instead of
the Blazorise package. Open Iconic's eight chevron/plus uses move to Font Awesome, and the Open
Iconic font and its render-blocking `@import` are removed.
